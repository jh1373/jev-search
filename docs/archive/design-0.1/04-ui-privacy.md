# 04. UI・設定・プライバシー設計

対象: `src/ui/*`, `src/main.ts`

## 1. 画面構成

| 画面 | 実装 | 役割 |
|------|------|------|
| 検索ビュー | `ItemView` 右サイド | クエリ入力・結果リスト・モード切替(ローカル/Jev 判定) |
| 結果アイテム | DOM | パス・見出し・抜粋・score バッジ・answers バッジ |
| 送信プレビュー | `Modal` | 送信する抜粋一覧・推定トークン/コスト・承認/キャンセル |
| 設定タブ | `PluginSettingTab` | 後述スキーマ |
| 使用量表示 | 結果ビュー上部 | 直近レイテンシ・トークン・累積推定コスト |

## 2. 結果アイテムの表示要件

```
┌─────────────────────────────────────────┐
│ 📄 プロジェクト管理の原則        [answers 2.0] │
│   └ 見出し: 優先順位の付け方                     │
│   「…抜粋の先頭 120 文字…」                     │
│   BM25 #3 → Jev #1   ▲2                 │
└─────────────────────────────────────────┘
```

- score・confidence・順位変化を必ず表示(P7)
- クリックでノートを開き、該当見出しへスクロール

## 3. 送信プレビュー(ADR-007, P2)

- 初回検索時と設定変更後の最初の検索で表示。以降は「今後この内容で自動送信」
  を承認すれば省略可能(セッション単位)。
- 表示内容: 送信される抜粋テキスト・件数・推定トークン・推定コスト・宛先ドメイン
  (`api.typesafe.ai`)。
- 「除外フォルダに追加」をプレビュー上から直接実行できる。

## 4. 設定スキーマ

```ts
export interface JevSearchSettings {
  apiKey: string;            // 既定 ''。空なら Jev 機能は無効+案内表示
  model: string;             // 'jev-1.13.0'
  rerankEnabled: boolean;    // true
  fetchK: number;            // 50   BM25 で取得する候補数
  rerankTopN: number;        // 30   Jev に送る上位候補数
  keepAt: number;            // 1.0  related 以上で残す
  answersAt: number;         // 1.5  answers バッジしきい値
  timeoutMs: number;         // 4000
  maxStateChars: number;     // 60000
  showPreview: boolean;      // true  送信プレビューを出す
  estimateCost: boolean;     // true  コスト推定を表示
  excludedFolders: string[]; // ['.obsidian', 'templates', 'Attachments']
  excludedTags: string[];    // []    frontmatter タグでの除外
  cacheTtlMinutes: number;   // 30
  cacheMaxEntries: number;   // 500
}
```

- 設定変更時: キャッシュクリア、インデックスは不要(除外は検索時にフィルタ)。

## 5. プライバシー設計

| 項目 | 方針 |
|------|------|
| 送信内容 | プレビューで可視化した抜粋のみ。全本文は送らない(先頭 2,000 字/候補) |
| 除外 | フォルダ・タグ・`.obsidian` 等を既定除外。設定で追加 |
| ログ | 本文・クエリ・キーを含まない。console には障害種別のみ |
| テレメトリ | 一切送信しない(P5) |
| キー保存 | 設定 JSON 内平文(Obsidian 標準)。README で注意喚起。パストラバーサル等の入力はプラグインが新規に解釈しない |

## 6. エラーメッセージ方針

ユーザー向け文言は「原因 + 次の一手」で統一:

- `API キーが未設定です。設定 → Jev Search から登録してください`
- `API キーが拒否されました(401)。設定を確認してください`
- `レート制限中です。ローカル順で表示しています`
- `Jev 判定がタイムアウトしました。ローカル順の結果を表示しています`
- `オフラインの可能性があります。ローカル検索のみで動作しています`

## 7. アクセシビリティ

- キーボード操作: ↑/↓ で結果移動、Enter で開く、Esc で閉じる
- role 属性・aria-label を結果リストに付与
