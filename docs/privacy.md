# プライバシー / Privacy

この文書は、Jev Search が**何を端末の外に出し、何を端末内に残すか**を、実装に即して記述します。
推測や希望ではなく、コードと受入テストで確認できる範囲だけを書いています。

## 端末の外に出るもの

Jev Search は**既定で外部送信を行いません**。次の3つすべてを満たしたときにだけ、候補ノートの
抜粋が OpenRouter（経由先 TypeSafe）へ送信されます。

1. 設定で「Jevで並べ替え」を有効にし、APIキーを保存している
2. 検索したあと「Jevで並べ替え」ボタンを押した
3. **送信内容のプレビューを確認し、「送信」を押した**

送信されるのは**上位20件の候補ノートから作った抜粋**だけです。抜粋には**検索クエリの文字列が
含まれます**（Jevに「このノートはこのクエリにどれくらい合うか」を尋ねるため）。Vault全体、
ファイル名の一覧、フォルダ構造、候補以外のノートは送信しません。

承認した本文と実際に送る本文が同一であることは、受入テスト AT-03 で確認しています
（preview本文と送信本文のSHA-256が一致）。

## 端末内に残るもの

- 検索索引 — **メモリ上のみ**。Vaultに索引ファイルを書き込みません
- 設定（`data.json`） — 対象フォルダ、タグ、エンドポイント、キャッシュ保持時間
- APIキー — Obsidianの SecretStorage

### SecretStorageについて、正確に

ObsidianのSecretStorageは**プロファイル単位**で保存され、**Vault単位ではありません**。同じ
プロファイルの別のVaultからも参照できます。

この文書は、SecretStorageが**暗号化されているとも、同期されないとも主張しません**。保存方法と
同期の挙動はObsidian側の実装と利用者の同期設定に従います。Vaultと一緒に持ち運びたい場合は、
利用者自身が同期の範囲を確認してください。

## 実装していないもの

- テレメトリ、利用統計、クラッシュレポート — **実装していません**
- 検索履歴の保存 — 保存しません
- ノートの書き換え — 行いません（受入テスト S-04）

## キーの扱い

- キーは設定画面から保存し、SecretStorageに置きます。`data.json` には書きません
- キーをログ、エラー文、診断情報、README、Git、CIに出しません
- 「診断をコピー」が出すのは版・件数・設定値だけで、パス・本文・クエリ・キーを含みません
  （受入テスト AT-18）

## この文書の限界

受入テストの範囲は**合成Vaultと実Obsidian**です。実際のVaultで使う場合は、送信プレビューで
毎回内容を確認してください。プレビューはそのためにあります。
